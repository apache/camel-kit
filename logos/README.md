# Camel Kit logos

| File | What it is |
|------|-----------|

| `camel-kit-logo.svg` | The same artwork as an SVG wrapper around the raster (1120 x 1104 viewBox). It is not a traced vector; scale the PNG for other sizes. |

camel.apache.org (project cards, home page tile) and for the documentation
